# 🏫 School Administration System

A comprehensive desktop application designed to digitize and streamline school management processes. Built with **C# (.NET)** using a **5-Layer Architecture**, this system ensures secure data handling, role-based access control, and efficient scheduling.

## 🚀 Key Features

* **Role-Based Security:** Secure login system with different access levels for Administrators, Teachers, and Staff.
* **Academic Management:** Easy CRUD operations for Lessons, Curriculums, and Grades.
* **Teacher & Staff Administration:** Detailed profiles and assignment management for school personnel.
* **Advanced Architecture:** Designed with a scalable **5-Layer Architecture** (Presentation, Business, Data Access, Entity, Common) to ensure code maintainability.
* **Reporting:** Automated generation of lesson schedules and student lists.

## 🛠️ Technologies Used

* **Language:** C#
* **Framework:** .NET Framework (Windows Forms)
* **Database:** Microsoft SQL Server
* **ORM:** Entity Framework / ADO.NET
* **Architecture:** N-Tier Architecture (5 Layers)

## 📦 Installation

1.  Clone the repository:
    ```bash
    git clone [https://github.com/LegioNNN/School-Administration-System.git](https://github.com/LegioNNN/School-Administration-System.git)
    ```
2.  Open the solution file (`.sln`) in **Visual Studio**.
3.  Restore NuGet packages.
4.  Configure the connection string in `App.config` to match your SQL Server instance.
5.  Run the application!
